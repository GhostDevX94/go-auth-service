A RESTful user management service built with Go, providing user registration and authentication functionality with JWT tokens. This project demonstrates clean architecture, comprehensive testing, and modern DevOps practices.

## 🚀 Features

- **User Registration** - Secure user registration with password hashing
- **User Authentication** - JWT-based login system
- **Password Security** - Bcrypt password hashing
- **Input Validation** - Request validation using go-playground/validator
- **CORS Support** - Cross-origin resource sharing enabled
- **Request Logging** - Structured logging with logrus
- **Database Migrations** - SQL migration system
- **Clean Architecture** - Well-structured codebase following Go best practices
- **Comprehensive Testing** - Unit tests with mocks and integration tests
- **Docker Support** - Containerized application with Docker Compose
- **CI/CD Pipeline** - Automated testing and deployment with GitHub Actions
- **API Documentation** - Swagger/OpenAPI documentation
